=================================================
4. PHP REAL EN LAS VISTAS
=================================================

Las vistas frontend son PHP real, no simples archivos HTML renombrados.

La mayoría de vistas incluyen al inicio:

<?php require_once __DIR__ . '/../includes/page_context.php'; ?>

La vista del curso incluye:

<?php require_once __DIR__ . '/../../includes/page_context.php'; ?>

El archivo frontend/includes/page_context.php:
- inicia la sesión PHP;
- calcula el título de la página;
- obtiene el año actual;
- obtiene el rol de sesión;
- contiene la función page_escape() para escapar HTML.

=================================================
6. AUTENTICACIÓN Y USUARIOS
=================================================

Páginas:
- frontend/authentication/login.php
- frontend/authentication/register.php
- frontend/authentication/forgot-password.php

La autenticación utiliza las APIs del backend y sesiones PHP.

El registro público está desactivado.

frontend/authentication/register.php muestra un aviso indicando que las cuentas
son creadas por el administrador desde el dashboard.

backend/Api/register.php rechaza con HTTP 403 cualquier solicitud que no provenga
de una sesión autenticada con rol admin.

La creación de usuarios debe realizarse desde:

frontend/Interface_Administrador/usuarios.php

Usando:

backend/Api/usuarios.php

La API administrativa comprueba:
- sesión activa;
- rol admin;
- nombres;
- apellidos;
- correo;
- contraseña;
- rol;
- estado.

Las contraseñas se guardan usando password_hash().

- Cursos

- Reportes

El contenido se carga dinámicamente en el elemento:

El controlador principal es:

frontend/scripts/dashboard.php

Este controlador:
- lee el hash de la URL;
- carga las vistas PHP con fetch();
- inserta el contenido en #admin-content;
- carga hojas CSS de las vistas;
- carga scripts de usuarios, cursos y evaluaciones;
- actualiza el elemento activo del menú;
- carga correctamente rutas como #resultados;
- ejecuta el cierre de sesión mediante backend/Api/logout.php.
